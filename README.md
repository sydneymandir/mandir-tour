# Mandir Campus Tour

Self-guided visitor tour of BAPS Shri Swaminarayan Mandir, Sydney (Kemps Creek). Visitors open it from a QR code; it works offline once loaded, in English, Hindi, Gujarati and Nepali.

Live: https://sydneymandir.github.io/mandir-tour/

These are the published files only. The editable source (visitor text, map positions, build script) is kept in the Mandir tour folder on OneDrive.
